# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful and constructive, assume good intent, welcome newcomers, and
focus criticism on ideas and code rather than people. Harassment, discrimination and
personal attacks are not tolerated in issues, pull requests, discussions or any other
project space.

## Reporting

Report unacceptable behaviour privately to the project maintainers through the
contact listed in the repository's security policy or profile. Reports are handled
confidentially. Maintainers may remove content and restrict participation of anyone
who violates this code.
